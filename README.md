# Mntungwa ServiceDesk

Mntungwa ServiceDesk is a full-stack IT service desk application designed to help IT support teams manage support tickets in one place.

The project was built as a portfolio project to demonstrate practical skills in Java, Spring Boot, React, MySQL, REST APIs, and software development.

## Features

- Create support tickets
- View support tickets
- Edit existing tickets
- Delete tickets
- Ticket status management
- Ticket priority management
- Dashboard statistics
- REST API backend
- React frontend
- MySQL database integration
- Exception handling
- IT service desk workflow
